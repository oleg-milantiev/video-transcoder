# Кодированное хранение чувствительных данных

На основе sodium расширения я хочу создать инфраструктуру безопасного хранения данные пользователей.
Чтобы даже при утечке базы, без приватного ключа не было возможности чтения чувствительных данных.

- создай инфраструктурный сервис sodium.
- создай команду генерации пары ключей (вызовом метода этого сервиса)
- дополни UserSessionAuditListener. При успешном входе пользователя, закодируй cloudflare http_cf
заголовки в base64 строку вызовом нового сервиса. Её сохрани в user.profile.cf поле.
Публичный ключ будет в env.
- создай команду получения подробных данных о пользователе. Приватный ключ так же будет в env
(я не буду поставлять его в прод и эта команда не будет там работать).
- дополни develop/.env переменными ключа.
- добавь / исправь phpUnit тест метода, команд и UserSessionAuditListener. Проверь тесты.
