В frontend, на страницу карточки видео, в список пресетов нужно добавить колонку Resolution. В строках preset, где нет task, в этой колонке select с динамически наполняемым списком разрешений.

Справочный список высот задан в константе frontend. Это массив 144, 240, 360, 480, 720, 1080, 1440, 2160, 4320.
Используются только значения <= tariff.height.
Ширина при этом высчитывается, исходя из пропорций исходного видео. С округлением до целого.
Сортировка внутри селекта от большего к меньшему.

Если какая-то высота из списка совпадает с высотой видео,то вместо цифр выводим same as origin.

Пока что просто вывод новой колонки и этих select. Никакой другой функциональности.
