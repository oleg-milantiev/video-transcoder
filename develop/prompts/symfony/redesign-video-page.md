В frontend, на странице карточки видео серьёзные изменения.

Адаптируй frontend (symfony/assets) страницы видео для отображения нового VideoDetailsDTO. Показ данных видео использует поля dto.video.

Блок presets переименовать в Start new Video Transcoding Task. Уходим от табличного вывода. Выводи в цикле доступные юзеру пресеты.
В каждом пресете предлагается выбрать разрешение. Убери константу списка разрешений из frontend. Используй поле preset.bitrate.
Select меняем на вертикальный список кнопок Transcode to width x height (или same as origin).
Под каждой кнопкой выводится мелким шрифтом Expected Size. Рассчитывай размер, исходя из текущего битрейта этого разрешения и длительности видео.  
Если пресетов несколько, они отделены горизонтальной линией.

Далее блок Transcoding tasks. Это таблица с уже запущенными ранее по этому видео задачами.
Её логика очень похожа на существующую сейчас логику кодирования, обновления, отмены задачи. Всё, что раньше делалось для существующей задачи.
Если в DTO нет tasks данных, блок не выводится весь. Нет надписи no tasks или похожей.
